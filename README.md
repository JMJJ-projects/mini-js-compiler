# CompilationJohn

Vous vous trouvez dans la branche "parser_work" du projet de compilation.

********************************************************************************
Il s'agit d'une branche de travail offrant un exécutable qui analyse lexicalement
et syntaxiquement le code JS entré et accèpte un code correct dans le fragment
implémenté.

Pour lancer le programme il faut le compiler avec:

```bash
gcc -Wall main.c -o main
```
Puis le lancer avec

```bash
./main
```
